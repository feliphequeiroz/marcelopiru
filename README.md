# Marcelo Piru — Minisite MVP

MVP em **React + Vite + Tailwind CSS**, com dependências mínimas.

## Estrutura

```bash
marcelopiru-minisite-mvp/
  package.json
  index.html
  src/
    main.jsx
    App.jsx
  styles.css
  postcss.config.js
  README.md
```

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
