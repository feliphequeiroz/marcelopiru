## Publicação na Hostinger

1. Compacte os arquivos em `.zip` (na raiz, sem pasta extra).
2. No hPanel, abra **Gerenciador de Arquivos** do domínio.
3. Faça upload do `.zip` e extraia no `public_html`.
4. Acesse o domínio e valide os CTAs.
